📹 CCTV Wall

✕ Heads-up on Ring & app-only cameras. A web page can only show feeds a browser can open directly — an HLS (.m3u8) stream, an MJPEG stream, a snapshot JPEG URL, or an embeddable web player. Ring cameras and vendor-app-only cloud cameras don't expose those, so they can't stream here without a small always-on "bridge" (e.g. go2rtc). If a camera gives you a snapshot URL you can still add it as a near-live snapshot tile. Ask me to add a bridge later for true live Ring/cloud feeds.
