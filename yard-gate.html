⚙️ Gate setup

Configure the Tuya device that triggers the gate and (optionally) the sensor that reports it's open. You only do this once.

The Tuya keys aren't set on the worker yet. Add TUYA_ACCESS_ID and TUYA_ACCESS_SECRET as secrets in the Cloudflare dashboard, then Deploy.
Not sure of the code? Paste the device ID above, save, then use Read device below to see exactly what it exposes — the switch/trigger DP is the one to use here. Make sure the Tuya module is set to momentary / "inching" mode so it pulses the FAAC OPEN input rather than latching.
On your FAAC 415L, set an E145 OUT1/OUT2 (or the 452 warning-light) output to the "gate open" function, wire it into a Tuya contact sensor (share the 0V ground), then read that device below to find its state code.
Add the gate's DVR in the CCTV Wall first, then pick its camera here — the snapshot then shows in the safety dialog.
