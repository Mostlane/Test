Maximum earth-fault loop impedance (Zs)

BS 7671 Tables 41.3 / 41.4 (Cmin 0.95, U₀ 230 V). For MCBs / RCBOs the limit is set by the magnetic trip.

The tabulated value assumes conductors at operating temperature. A reading taken cold should sit at or below the 0.8× "rule-of-thumb" figure (GN3) — that's what the pass/fail uses. If the circuit is RCD-protected, fault protection is by the RCD instead — see the RCD tab (Zs ≤ 50 ⁄ I∆n). Fuse presets aren't built in yet; use BS 7671 Table 41.2/41.4 for those.

RCD operation & disconnection times

BS 7671 411.3 / Table 41.1 and GN3. Test at 0° and 180°, record the longer time.

RCD trip-time check (30 mA, additional protection)

A 30 mA RCD for additional protection must trip ≤ 300 ms at 1×I∆n and ≤ 40 ms at 5×I∆n. (A no-test-button or failed operation is a code — see Coding.)

Typical maximum external loop impedance (Ze): TN-S ≤ 0.8 Ω, TN-C-S (PME) ≤ 0.35 Ω, TT ≤ 21 Ω (RCD required). Confirm PFC is within the device's breaking capacity.

Insulation resistance

BS 7671 Table 61. Test between live conductors, and between live conductors and earth.

Where electronic equipment could be damaged, disconnect it or test live conductors connected together to earth. A reading far above the minimum (e.g. >299 MΩ / ∞) is normal for a healthy circuit; a low but passing value can still warrant investigation.

Ring final circuit continuity

End-to-end resistances (step 1 of the 3-step test). Line & neutral should match; r2 depends on the CPC size.

Healthy ring: r1 ≈ rn, and r2 ≈ (line ÷ cpc) × r1 (e.g. 2.5/1.5 mm² → r2 ≈ 1.67 × r1). Cross-connected readings at each socket should be near-uniform; the expected R1+R2 = (r1 + r2) ⁄ 4. A high/odd reading points to a break, spur, or cross-connection.

Observation coding — C1 · C2 · C3 · FI

Per IET Guidance Note 3 & Best Practice Guide 4. The code depends on the actual situation — these are typical examples, not rulings.

C1 Danger present

Risk of injury — immediate remedial action required. (Exposed live parts, incorrect polarity, unsafe conductor.)

C2 Potentially dangerous

Urgent remedial action required. (No/inadequate earthing or bonding, no CPC at an accessory, damaged accessory.)

C3 Improvement recommended

Not a fail on its own. (No RCD where now recommended but not required at install, no SPD, old cable colours with a warning notice.)

FI Further investigation

Required without delay — something couldn't be fully assessed and may reveal a danger.
Overall: the report is UNSATISFACTORY if there is any C1, C2 or FI. C3 items alone → still Satisfactory (but recorded).

Common observations → typical code

Curated examples per BS 7671:2018+A2:2022 / GN3 / BPG4 — guidance only, not rulings. The Type AC → Type A, SPD and AFDD items are amendment-driven and usually C3, but escalate where the circuit specifically needs it (e.g. a Type AC RCD on an EV charge point or known DC-fault equipment is typically C2).
