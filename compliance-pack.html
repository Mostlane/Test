📦 Southern Co-op compliance pack

What this builds

A folder for each store type (Cobra · ELS · ELS Private · Retail). Inside each one there is a folder per store named "code - store name", and inside that a folder per compliance type holding only the latest certificate. Pump, Forecourt, PV and EV folders only appear where the store needs them. A Compliance tracker.xlsx goes at the top showing what's there, what's missing and what's overdue. Active stores only.

Writing folders to your computer needs Chrome or Edge on a desktop/laptop. You can still download the tracker spreadsheet below.
