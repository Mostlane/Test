🧭 Engineer skills

🛠 Areas of work

The list of work types you rate engineers on, tag jobs with and route to subcontractors. Each has a description of exactly what it covers and what it doesn't — the auto-detection and the AI both work from it, so the sharper the description, the better jobs are recognised. Edit any of them, remove one, or add your own. Changes save automatically.

⭐ Engineer competency

Rate each engineer 1–5 stars for the work types they're competent in. Leave blank if they don't do that work. The scheduler uses this to prefer the right engineer for a job (a ⚠ shows if none is rated). Tap a star to set, tap it again to clear. The grey trade rows set every type in that trade at once — then adjust the odd one. Tap a type's name to read what it covers. Saves automatically.
