Setting it up (one-off, Cloudflare + Outlook)

    
    
      
  1. Cloudflare → a domain whose DNS is on Cloudflare → Email → Email Routing → Enable. Add a custom address, e.g. jobs@your-domain, action Send to a Worker → mostlane-api.
    2. 
      
  2. Outlook (web) → Settings → Mail → Rules → Add rule: when the message is from noreply@concerto.co.uk (add any other job senders) → Forward to jobs@your-domain. Use forward, not redirect, so the copy is sent from your own address and passes the spam checks.
    3. 
      
  3. If the rule refuses to forward outside the company, an admin must allow automatic external forwarding for that mailbox (Microsoft 365 Defender → Anti-spam → Outbound policy).
    4. 
      
  4. Send yourself a test job email, then check Recent emails above. Run alongside the Zapier zap for a few days — the same job is never duplicated (it matches by reference) — then switch the zap off.
